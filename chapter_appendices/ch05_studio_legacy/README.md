# Archived Chapter 5 studio walkthrough

This is the support-ticket example used in an earlier version of Chapter 5. The
current chapter uses the personal calendar agent instead. Imports in these
runnable copies point to this archive; their behavior remains unchanged.

Run the preserved walkthrough from the repository root:

```powershell
python chapter_appendices/ch05_studio_legacy/03_memory_learning.py --output tmp/studio-legacy-run
```

The output directory must be new or empty. The preserved regression tests are
in `tests/test_studio_memory_walkthrough.py`.
