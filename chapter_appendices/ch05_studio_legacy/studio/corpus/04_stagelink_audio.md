# StageLink: restoring a playtest microphone

Document ID: AUDIO-04. Revision: 1. Owner: Player Research.

## Checking the selected input

StageLink can retain the laptop microphone after a USB headset is connected. Compare the selected StageLink input with the headset shown in the operating system before changing drivers. An audible headset speaker does not prove that its microphone is selected.

## Testing a change

Select the connected headset as the StageLink input and record a short local test. The teaching simulator calls this `select_stagelink_input` and confirms whether the microphone meter responds. Keep the test local until the participant knows recording is enabled.

## Escalating a remaining problem

If the headset is absent from the input list, check its connection and the application's microphone permission. Report the selected device and permission state if the local test still fails. A remembered fix for Leo's USB headset should not automatically become the fix for every participant's equipment.
