# Historical Chapter 5 RL primer

These scripts belonged to an earlier version of Chapter 5. The chapter now replaces the separate return, Q-learning, and bandit demonstrations with a casebook explanation and three current listing files.

- `01_returns.py`: discounted-return arithmetic.
- `02_value_learning.py`: the earlier value-update and Q-learning comparison.
- `03_exploration.py`: the earlier bandit demonstration.

They are preserved for comparison with earlier versions and are not additional examples or exercises in the current chapter. All three use only Python's standard library.
